# HATEEKUB

A multiplayer game matching platform that helps players find teammates
based on their preferred game, role, rank, and play time.

## About the Project

HATEEKUB is a web application for finding teammates across multiple games.
Users can create or join rooms, specify their preferred roles and ranks,
and communicate with other players through the room chat.

The project was developed as a web application using ASP.NET Core MVC.

## Features

- 🎮 Support multiple games
- 👥 Create and join game rooms
- 🔎 Match players based on rank and role
- 🏆 Rank-based player matching
- 🔐 Private / public rooms
- 💬 Real-time room chat
- ⏰ Schedule play time
- 👤 User profile and avatar
- 🚪 Room management
- 📋 Queue system for full rooms
- 📱 Responsive web interface
